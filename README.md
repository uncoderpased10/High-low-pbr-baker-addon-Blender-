# High-low-pbr-baker-addon-Blender-
A streamlined Blender add-on for fast High-to-Low Poly texture baking. Automates image texture setup, shader node wiring, ray extrusion/cage configuration, and multi-map Cycles baking (Normal, Ambient Occlusion, Diffuse, Roughness, and more) directly from the 3D Viewport N-Panel.
